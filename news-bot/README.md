# 🤖 ربات اخبار تلگرام با GitHub Actions

یک ربات هوشمند و تعاملی که اخبار جدید را بر اساس کلمه کلیدی دلخواه شما از منابع مختلف جمع‌آوری کرده و به صورت مستقیم به تلگرام ارسال می‌کند.

## ✨ ویژگی‌ها

- 💬 **ربات تعاملی**: کاربران می‌توانند مستقیماً از طریق تلگرام با ربات کار کنند
- 🔍 **کلمه کلیدی شخصی**: هر کاربر کلمه کلیدی خود را تنظیم می‌کند
- 📰 **منابع متعدد**: دریافت اخبار از Google News و سایر منابع معتبر
- 🔄 **جلوگیری از تکرار**: اخبار تکراری برای هر کاربر ارسال نمی‌شود
- ⏰ **بررسی خودکار**: اجرای دوره‌ای برای تمام کاربران
- 🚀 **اجرای دستی**: امکان جستجوی فوری با کلمه کلیدی دلخواه
- 💰 **کاملاً رایگان**: استفاده از GitHub Actions بدون هزینه

## 🚀 راه‌اندازی سریع

### مرحله ۱: آپلود در GitHub

1. این مخزن را به حساب GitHub خود آپلود کنید
2. یا فایل‌ها را در یک مخزن جدید کپی کنید

### مرحله ۲: ساخت ربات تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید
2. دستور `/newbot` را ارسال کنید
3. نام و نام کاربری ربات را وارد کنید
4. **توکن ربات** را دریافت و ذخیره کنید

### مرحله ۳: دریافت Chat ID

برای دریافت شناسه کاربری خود:

1. به [@userinfobot](https://t.me/userinfobot) پیام دهید
2. ID عددی خود را دریافت کنید (مثلاً: `109762835`)

یا از آدرس زیر استفاده کنید (توکن خود را جایگزین کنید):
```
https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates
```

### مرحله ۴: تنظیم Secrets در GitHub

1. به مخزن GitHub خود بروید
2. به **Settings** → **Secrets and variables** → **Actions** بروید
3. روی **New repository secret** کلیک کنید
4. Secret زیر را اضافه کنید:

| نام Secret | مقدار | توضیحات |
|-----------|------|---------|
| `TELEGRAM_BOT_TOKEN` | توکن دریافتی از BotFather | توکن ربات تلگرام |

### مرحله ۵: فعال‌سازی GitHub Actions

1. به تب **Actions** در GitHub بروید
2. اگر پیامی درباره فعال‌سازی Actions دیدید، آن را تأیید کنید
3. اولین workflow را اجرا کنید تا همه چیز تست شود

## 📱 نحوه استفاده از ربات

### روش ۱: اجرای ربات تعاملی (توصیه شده)

این روش به شما امکان می‌دهد مستقیماً از طریق تلگرام با ربات کار کنید:

1. ربات را در یک سرور یا سرویس ابری (مثل Railway, Heroku, یا VPS) اجرا کنید
2. در تلگرام به ربات خود پیام دهید
3. دستورات زیر را استفاده کنید:

#### دستورات ربات:

- `/start` - شروع ربات و نمایش پیام خوش‌آمدگویی
- `/setkeyword <کلمه>` - تنظیم کلمه کلیدی برای جستجوی اخبار
  - مثال: `/setkeyword هوش مصنوعی`
  - مثال: `/setkeyword technology`
- `/getnews` - دریافت آخرین اخبار بر اساس کلمه کلیدی شما
- `/status` - مشاهده وضعیت کلمه کلیدی و آمار اخبار دریافتی
- `/help` - نمایش راهنمای کامل

#### نمونه مکالمه:

```
شما: /setkeyword تکنولوژی
ربات: ✅ کلمه کلیدی شما تنظیم شد: 🔍 تکنولوژی
     حالا می‌توانید از دستور /getnews برای دریافت اخبار استفاده کنید!

شما: /getnews
ربات: 🔍 در حال جستجوی اخبار برای: تکنولوژی...
     لطفاً صبر کنید...

[ارسال ۵ خبر جدید]

ربات: ✅ تعداد ۵ خبر جدید برای شما ارسال شد!
```

### روش ۲: استفاده از GitHub Actions (بررسی خودکار)

برای بررسی خودکار اخبار تمام کاربران:

1. به تب **Actions** در GitHub بروید
2. روی **News Bot - Interactive** کلیک کنید
3. دکمه **Run workflow** را بزنید
4. Action را انتخاب کنید:
   - `check_news`: بررسی خودکار برای تمام کاربران
   - `send_news`: جستجوی دستی برای کاربر خاص

#### برای جستجوی دستی:

- **Action**: `send_news`
- **Telegram User ID**: شناسه کاربر (مثلاً: `109762835`)
- **Keyword**: کلمه کلیدی (مثلاً: `هوش مصنوعی`)

## 🔧 اجرای ربات تعاملی روی سرور

برای اجرای دائمی ربات تلگرام:

### روی VPS یا سرور لینوکس:

```bash
# نصب وابستگی‌ها
pip install -r requirements.txt

# اجرای ربات
export TELEGRAM_BOT_TOKEN="YOUR_BOT_TOKEN"
python news_bot.py
```

### استفاده از systemd (برای اجرای دائمی):

فایل `/etc/systemd/system/news-bot.service` را ایجاد کنید:

```ini
[Unit]
Description=Telegram News Bot
After=network.target

[Service]
Type=simple
User=youruser
WorkingDirectory=/path/to/news-bot
Environment=TELEGRAM_BOT_TOKEN=YOUR_BOT_TOKEN
ExecStart=/usr/bin/python3 /path/to/news-bot/news_bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

سپس:

```bash
sudo systemctl daemon-reload
sudo systemctl enable news-bot
sudo systemctl start news-bot
sudo systemctl status news-bot
```

### استفاده از Docker:

فایل `Dockerfile`:

```dockerfile
FROM python:3.11-slim

WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

ENV TELEGRAM_BOT_TOKEN=""

CMD ["python", "news_bot.py"]
```

اجرا:

```bash
docker build -t news-bot .
docker run -d \
  -e TELEGRAM_BOT_TOKEN="YOUR_TOKEN" \
  --name news-bot \
  news-bot
```

## 📊 نحوه کار

### ربات تعاملی:

1. کاربر ربات را در تلگرام شروع می‌کند
2. با دستور `/setkeyword` کلمه کلیدی خود را تنظیم می‌کند
3. با دستور `/getnews` آخرین اخبار را دریافت می‌کند
4. اخبار ارسالی ذخیره می‌شوند تا تکراری ارسال نشوند

### GitHub Actions Scheduled:

1. Workflow به صورت دوره‌ای اجرا می‌شود
2. کلمات کلیدی تمام کاربران را بارگذاری می‌کند
3. برای هر کاربر اخبار جدید را جستجو می‌کند
4. اخبار جدید را به تلگرام ارسال می‌کند
5. وضعیت را ذخیره می‌کند

## ⚠️ نکات مهم

- 🔐 **هرگز توکن ربات را در کد قرار ندهید** - فقط از Secrets استفاده کنید
- 📊 GitHub Actions برای مخازن عمومی محدودیت دارد (حدود ۲۰۰۰ دقیقه در ماه)
- 📱 برای اجرای دائمی ربات، نیاز به سرور یا سرویس ابری دارید
- 🔄 GitHub Actions برای بررسی‌های دوره‌ای مناسب است اما برای پاسخگویی لحظه‌ای نه
- 💡 توصیه: از ربات تعاملی روی سرور + GitHub Actions برای backup استفاده کنید

## 🛠 عیب‌یابی

### ربات تلگرام پاسخ نمی‌دهد

- بررسی کنید توکن صحیح باشد
- مطمئن شوید ربات در حال اجراست
- لاگ‌ها را بررسی کنید

### GitHub Actions اجرا نمی‌شود

- بررسی کنید Actions در Settings فعال باشد
- Secrets را بررسی کنید
- به تب Actions بروید و لاگ‌ها را ببینید

### اخبار ارسال نمی‌شود

- Chat ID را بررسی کنید
- کلمه کلیدی را تغییر دهید
- محدودیت‌های تلگرام را بررسی کنید

### خطای توکن

- توکن را در BotFather revoke و مجدد دریافت کنید
- از صحت توکن در Secrets مطمئن شوید
- توکن را در محیط متغیر تنظیم کنید
